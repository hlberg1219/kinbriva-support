# Innexis Privacy Policy

**Effective: November 5, 2026**

Innexis 1.0 is local-first and does not require an account.

## Information stored on the device

Innexis may store notes, dates, monetary amounts, reference numbers, photos, screenshots, documents, source excerpts, timeline entries, and outcome records that the user chooses to enter or import.

## Data collection

Innexis 1.0 does not send user-created matters, imported evidence, or extracted commitment details to an Innexis-operated server.

Version 1.0 contains no advertising SDK, analytics SDK, cross-app tracking, or data-broker integration.

## Notifications and Face ID

Local reminders use Apple's notification system. Notifications are off by default and permission is requested only if reminders are enabled.

Optional Face ID or device authentication is handled by Apple's LocalAuthentication framework. Innexis does not receive biometric data.

## Exports

Users decide when and where an exported matter record is shared. Once information is shared to another app or service, that destination's privacy practices apply.

## Deletion

Users can delete individual matters or erase local Innexis data using the app's data controls.

## Future changes

If a future version adds cloud sync, accounts, analytics, or off-device processing, this policy and the App Store privacy disclosures will be updated before release.
