# Innexis

**Keep the promise. Verify the outcome.**

Innexis is a local-first iPhone app for tracking refunds, claims, repairs, reimbursements, warranties, callbacks, deadlines, evidence, follow-ups, and verified outcomes.

- [Privacy policy](PRIVACY.md)
- [Support](SUPPORT.md)

Version 1.0 does not require an account, does not include ads or analytics SDKs, and does not send user-created matters or evidence to an Innexis-operated server.
