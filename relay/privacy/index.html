INNEXIS RELAY

Privacy

Effective November 5, 2026

Local-first design

Innexis Relay is designed to run automation on a computer controlled by the user. Version 0.1.0 does not require an Innexis cloud account or Relay subscription.

Information on iPhone and iPad

The app may store the local-network address of the paired Relay computer, an API pairing key in Apple Keychain, and temporary workflow/run/monitor status returned by that computer.

Information on the Relay computer

The local engine may store persistent browser profiles and cookies, workflow definitions and inputs, run history and screenshots, monitor schedules/status, and optional GitHub or App Store Connect credentials configured locally by the user.

Local network and pairing

The companion app connects to the Relay engine over a trusted local network. QR pairing uses a cryptographically random, short-lived one-time code. The permanent local API key is returned only after that code is exchanged with the Relay computer and is then stored in Apple Keychain. Relay does not silently upload the local browser profile to an Innexis-operated Relay cloud.

Third-party websites

Relay can open third-party websites at the user's direction. Website credentials, authentication, MFA, CAPTCHAs, service limits, and account permissions remain governed by the third party. Relay does not bypass access controls.

Tracking, advertising, and analytics

Version 0.1.0 does not track users across apps or websites, include an advertising SDK, or include a third-party analytics SDK.

Deletion

Deleting the iPhone/iPad app removes its app data according to iOS behavior. Removing the Relay engine's local data directory removes its locally stored profiles, runs, screenshots, workflows, monitors, and generated API key from that computer.
