INNEXIS RELAY

Support

Setup and troubleshooting for the local Relay engine and iPhone/iPad companion.

Start the Relay engine

  1. Install Node.js 20 or later on the computer.
  2. Open the Innexis Relay folder.
  3. Run the included Mac, Windows, or shell launcher.
  4. Relay opens at http://127.0.0.1:4317 on the computer.

Pair an iPhone or iPad

  1. Keep the computer and iPhone/iPad on the same trusted network.
  2. Configure Relay for local-network access rather than public internet exposure.
  3. Enter the computer's local-network Relay address and the generated API key in the app.
  4. The iOS app stores the API key in Apple Keychain.

Sign-in and MFA

When a workflow needs a website login, Relay pauses. Complete sign-in or MFA directly in the browser on the computer, then resume the workflow. Do not place passwords in workflow files.

Recurring monitors

Only autonomous workflows can run as unattended monitors. Workflows that require a person to sign in or approve a step stay manual.

Troubleshooting

The phone cannot connect

Confirm both devices are on the same trusted network, the Relay engine is running, the server address is correct, and local firewall rules allow the configured Relay port.

A workflow is waiting

Open the computer browser, complete the requested sign-in/MFA or other manual checkpoint, then choose Resume in Relay.

A website changed

Website selectors can change. Update the local workflow definition rather than bypassing the website's access controls.

Privacy and security

Do not expose the Relay port directly to the public internet. Keep pairing keys and App Store/GitHub credentials local and private.
