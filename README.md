# Kinbriva support

Public support and privacy documentation for Kinbriva by Innexis.

This repository contains the static website pages and their CSS/SVG assets. The native iPhone and iPad application is maintained separately.

Publish the `main` branch root with GitHub Pages. Pages use relative links so the project subdirectory works correctly. There are no scripts, upload forms, trackers, or build dependencies.

- Home: `index.html`
- App support: `support/index.html`
- Privacy policy: `privacy/index.html`

The published documentation describes native version 0.1.0. Live mailbox connections, portal synchronization, cloud sharing and paid subscriptions are not active in that version.
