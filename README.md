# Kinbriva support

Public support and privacy documentation for Kinbriva by Innexis.

This repository contains the static website pages and their CSS/SVG assets. The native iPhone and iPad application is maintained separately.

Publish the `main` branch root with GitHub Pages. Pages use relative links so the project subdirectory works correctly. There are no scripts, upload forms, trackers, or build dependencies.

- Home: `index.html`
- App support: `support/index.html`
- Privacy policy: `privacy/index.html`

## Kinbriva 0.2.0 release branch

The `kinbriva-0.2.0-release` branch prepares the public documentation required for the 0.2.0 App Store update. It covers the redesigned Today / Calendar / Messages / Records / Casebook experience, Parenting Log, Handoff Brief, schedule changes, richer expenses, Medication Center, Apple Calendar handoff, local/offline storage, iPhone Duo readiness, and the planned $10.99/year Kinbriva Plus product.

Do not merge this documentation branch to `main` until the 0.2.0 native release gates are ready for App Review. The current live public pages on `main` remain the documentation for the released/reviewed version until then.
